Precondiciones

  • El sistema debe tener cargado el catálogo de zapatos activos.
  • Debe existir al menos 1 par en inventario de la talla seleccionada.
  • La pasarela de pago o terminal POS debe estar en línea.

Poscondiciones

  • Descuento automático del stock por cada modelo y talla vendida.
  • Registro de la transacción en la base de datos de ventas.
  • Generación del recibo / ticket fiscal con número correlativo único.

Flujo Principal de Eventos (Paso a Paso)

1
Exploración y Filtrado: El usuario o vendedor explora la lista de productos y aplica filtros por tipo de calzado (deportivas, botas) o talla específica (38-44).
2
Selección de Talla y Agregar al Carrito: Se selecciona la talla del calzado deseado. El sistema verifica disponiblidad previa de stock y lo añade a la orden.
3
Cálculo de Importes: El sistema calcula automáticamente el Subtotal, el IVA correspondiente (13%) y el Total a abonar.
4
Ingreso de Datos de Facturación: Se completa el formulario con nombre del cliente, dirección de entrega y selección de método de pago (Tarjeta / Efectivo).
5
Procesamiento y Confirmación: El sistema valida el pago, reduce las existencias en inventario y despliega el ticket digital imprimible.

Flujos Alternativos y Excepciones

Excepción E1: Talla Sin Stock

Si la talla seleccionada no posee unidades (Stock = 0), el botón de compra se inhabilita automáticamente impidiendo agregar el producto.

Excepción E2: Pago Rechazado

Si la entidad bancaria o el cliente cancela la operación, el sistema lanza una alerta de rechazo, no descuenta existencias y mantiene el carrito intacto.
